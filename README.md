# Complemento do Trabalho de Linguagens de Programação

Este repositório foi criado como material complementar ao trabalho de Linguagens de Programação, com os códigos completos usados no trabalho podendo ser executados.

## Estrutura

Cada pasta representa um exemplo diferente:

- `1/` - goroutines e canais
- `2/` - select com timeout
- `3/` - defer, panic e recover
- `4/` - múltiplos valores de retorno e erros como valores
- `5/` - interfaces implícitas
- `6/` - genéricos com restrições de tipo
- `7/` - composição por embutimento de structs
- `8/` - slices

## Como usar

Cada arquivo pode ser executado individualmente com Go:

```bash
go run 1/cod1.go
```

ou, dependendo do exemplo:

```bash
go run 8/cod8.go
```
